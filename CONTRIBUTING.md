# Contributing Guidelines

Thank you for contributing to the New Vape custom MVC platform!

## Development Guidelines
1. Maintain the custom MVC separation:
   - **Controllers**: Located in `app/Controllers/`
   - **Models**: Located in `app/Models/`
   - **Views**: Located in `views/`
   - **Routes**: Configured in `config/routes.php`
2. Keep UI templates clean and logic separated.
3. Assets should reside in `public/assets/` or `assets/`.
4. Test all URL endpoints and responsive screens before committing.
